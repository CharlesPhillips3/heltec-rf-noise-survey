Heltec V3 RF Survey · Flasher

Installs the 902–928 MHz survey firmware on a Heltec WiFi LoRa 32 V3 straight from this page. It needs Chrome or Edge on a Windows, Mac, Linux or ChromeOS computer.

Download the flasher to your computer

Pages inside Claude aren't allowed to use USB. Save the flasher as a file, then double-click heltec-flasher.html. It opens in your browser with USB access and works the same way. Make sure it opens in Chrome or Edge; if not, right-click → Open with → Chrome. Keep the file for future updates.

1

Firmware

From your GitHub repo: heltec-rf-survey → Releases → newest “Firmware build” → heltec-rf-survey-merged.bin.

2

Connect the Heltec

Plug it in with a data USB-C cable, click Connect, and pick CP2102 / USB to UART (Windows: COMx · Mac: cu.usbserial / SLAB_USBtoUART). No port listed? Install the Silicon Labs CP210x driver, or try another cable.

not connected

Won't connect? Hold PRG, tap RST, release PRG, then click Connect again. “No compatible devices found”? Tick Show all serial ports. If the list is still empty, the computer can't see the board: try another USB-C cable (many are charge-only) or another USB port.

Board tools

Download survey log copies the survey CSV off a board that's running the survey firmware (no Bluetooth or Wi-Fi needed). A full log takes up to about a minute.

Analyze survey shows the full report on this screen: street map, GO stations, noisiest spots, spectrum, waterfall and timeline. It opens automatically after a log download, or you can pick any survey CSV (from this flasher, the Bluefy page's Save CSV, or the board's Wi-Fi page). Save report makes one HTML file you can email.

Back up board saves a complete copy of everything on the board (8 MB: its current firmware, settings and logs) as a .bin. Do this before installing if you might want the old firmware back. Restore it later by choosing that .bin in step 1 and installing it. Takes about 2 minutes.

idle
Done. The Heltec is restarting with the new firmware. The OLED should show RF Survey 902-928, then Floor … Med …. The board's startup messages appear below. On the first boot after an erase, setting up log storage takes a little longer.
